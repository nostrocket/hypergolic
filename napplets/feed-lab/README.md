# Feed Lab

Unsigned embedded fixture for the selected NAP-RELAY query and subscription profiles. Uses genuine SDK 0.27.2. Query notes sends editable NIP-01 filters; Query empty sample uses limit zero. Distinguishes loading, successful results, empty EOSE and errors. Untrusted note content is rendered only as text. Start live feed streams signed matches before and after EOSE; Close live feed closes its SDK handle. The feed retains 32 rows and an editable draft. No direct networking, signing or persistent storage.

Run `pnpm install --frozen-lockfile`, then `pnpm verify`. Browser mocks establish SDK/UI behavior; native and published journeys need separate receipts. Shell Settings exposes the embedded fixture after its generated bytes are reviewed and pinned. The [subscription profile](../../docs/relay-subscriptions.md) records the confirmed lifecycle and both native hosts’ scoped acceptance; full published/physical compatibility remains open.


Public identity controls now use genuine SDK reads. State Lab covers public profile,
relay preferences, follows, separately approved mutes/bookmarks/pins/interests,
accepted badges and explicit unsupported/deferred results. Feed Lab offers an
explicit follows read without changing query routing. See the selected
[public identity contract](../../docs/public-identity-data.md) and
[native acceptance drivers](../../tests/native/identity-data/README.md).

JSON filter and routing editors disable autocorrection, capitalization, autofill
and spelling assistance, with a URL keyboard hint for older mobile WebViews.
They preserve the entered options; the draft keeps its existing text editor.
A physical Android run observed `toInboxes` becoming `to inboxes` before this
change. Browser typing/blur tests cover exact SDK delivery; a desktop browser
cannot prove mobile keyboard behavior. The previous bundled artifact remains
byte-pinned as `feed-lab-v1` for saved sessions, with its original authority.
It is excluded from fresh openings and fixture publication.
